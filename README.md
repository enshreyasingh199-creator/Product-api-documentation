# Product-api-documentation

## Overview

This project provides documentation for a sample REST API used to manage product information.
This documentation explains how to retrieve,search,update,create and delete products using HTTP requests.
The API was tested using Postman.


## Audience

This documentation is intended for:

- Beginners
- API users
- QA Testers
- Technical Support teams
- Anyone learning how REST API work


## What you can do

Using this API, you can:

- Retrieve a list of products
- Retrieve a specific products
- Search for products
- Create a product
- Update a product
- Delete a product


## HTTP Methods

| Method | Purpose |
|---|---|
| GET | Retrieve information |
| POST | Create new product |
| PUT | Update a product |
| DELETE | Delete a product |
